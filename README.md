# AI-Powered-KNUST-Security-App


KNUST-Security-App is an AI-driven mobile application designed to enhance campus security. The app enables real-time incident reporting, emergency alerts, and AI-powered security monitoring using AWS SageMaker. Built with **React Native**, **Expo**, and **AWS services**, CampusShield ensures a safer campus environment for students, staff, and security personnel.

---

## 🚀 Features

✅ **Real-time Incident Reporting** – Report security incidents with images, location, and descriptions.  
✅ **AI-Powered Threat Detection** – AWS SageMaker analyzes patterns to detect security threats.  
✅ **Emergency SOS Alerts** – One-tap emergency alerts notify security officers instantly.  
✅ **Live Security Dashboard** – Security personnel monitor reports via a web interface.  
✅ **Push Notifications** – AWS SNS sends instant security alerts to users.  
✅ **Secure & Scalable Backend** – Built with Node.js, Express, and Amazon RDS.  

---

## 🏗️ Tech Stack

### 📱 **Frontend**
- React Native (Expo)
- React Navigation
- Tailwind CSS

### 🖥️ **Backend**
- Node.js, Express.js
- Amazon dynamodb 

### 🔍 **AI & Security**
- AWS SageMaker (Pattern Detection)
- AWS IAM (Security & Authentication)

### ☁️ **Cloud Services**
- AWS Lambda (Serverless Functions)
- AWS SNS (Push Notifications)
- AWS S3 (Incident Media Storage)
